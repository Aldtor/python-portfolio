> **Lisa** is my personal AI voice assistant built entirely from scratch in Python.

- 🗣️ Speaks to you using `pyttsx3` (Text-to-Speech)
- 🎤 Listens via microphone using `speech_recognition`
- 🧠 Has memory — saves conversations in JSON
- 💬 Custom personality and responses
