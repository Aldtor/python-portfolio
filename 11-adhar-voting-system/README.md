# Aadhaar-Style Demo and Voting Prototype

This folder contains educational prototypes only. They are **not connected to UIDAI, the Government of India, or any election service**, and they do not verify real identities, register voters, or securely record votes.

**Use fictional test values only. Never enter a real Aadhaar number or other personal information.** The `gpchat.py` example writes the supplied name and ID into a local HTML file at a hard-coded Desktop path. That file is plain local data, not a secure Aadhaar document.

## Files

| File | Description |
|------|-------------|
| `adhar.py` | Local name/ID comparison and correction exercise |
| `gpchat.py` | Local HTML card demo using fictional values |
| `Voting System.py` | Incomplete prototype; no real identity verification or vote recording |
| `satyammodule.py` | Utility functions for number and string exercises |

## Concepts Used

- Functions and modules
- Local file handling and HTML output
- `webbrowser` and `datetime`
- Basic input and conditionals

The examples are for programming practice only. They do not provide government identity services or election security.
