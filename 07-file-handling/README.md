# 📁 File Handling

Python programs for reading, writing, and managing files using pickle and file I/O.

| File | Description |
|------|-------------|
| `pickle.py` | Store student records to binary file using pickle |
| `pickle22.py` | Advanced pickle usage |
| `unpickle.py` | Read and display pickled data |
| `prsc.py` | Practical file read/search operations |

> 💡 File handling is essential for persistent data storage — these programs use Python's `pickle` module and standard file I/O.
