# 🔤 String Operations

Programs that work with strings — slicing, searching, vowels, and case operations.

| File | Description |
|------|-------------|
| `slicing string.py` | String slicing techniques |
| `occurence of substring.py` | Count occurrences of a substring |
| `vowel.py` | Count vowels in a string |
| `vowelconst.py` | Count vowels and consonants |
| `uppercaseloc.py` | Find uppercase letter positions |
| `w1w2.py` | Word manipulation programs |

> 💡 String operations are essential for text processing in any Python project.
