# 🧠 Python Data Types Explorer

An **interactive menu-driven Python program** covering all major Python topics — a comprehensive learning tool and showcase.

## 📁 Files

| File | Description |
|------|-------------|
| `main.py` | Full interactive system with menus for all Python concepts |
| `data_types_menu.py` | Menu covering strings, lists, tuples, dictionaries |

## 🎯 Menu Options

The program provides an interactive console menu covering:

1. ➕ **Arithmetic Operations** — `+`, `-`, `*`, `**`, `/`, `//`, `%`
2. 🔁 **Relational Operators** — compare numbers
3. 🔢 **Number Programs** — Prime, Armstrong, Palindrome, Fibonacci, Factorial, Spy, Niven
4. 🔷 **Nested Loops** — Triangle, Square, Diamond patterns

## 💡 Concepts Used
- While True menu loop
- Nested if/elif/else
- All arithmetic and relational operators
- Multiple number theory algorithms in one file
