# 🤖 Satya Instagram Bot

An **Instagram automation bot** built using the `InstaPy` library — auto-comments on posts with personalized messages.

## 📁 Files

| File | Description |
|------|-------------|
| `bot.py` | Main bot script — logs in, auto-comments on posts |

## ⚡ Features
- 🔐 Instagram login automation
- 💬 Randomized comment pool with 15+ unique messages
- 🏷️ Auto-tags users in comments
- 🧠 Uses `smart_run` context manager for safe session handling
- 👻 Headless browser mode support

## Requirements
```
pip install instapy
```

## 💡 Concepts Used
- Third-party library integration (`InstaPy`)
- List of comments (randomized selection)
- Context managers (`with smart_run`)
- Python automation & web interaction

> ⚠️ This bot was built for learning automation concepts. Use responsibly and in accordance with Instagram's Terms of Service.
