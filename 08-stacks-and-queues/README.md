# 📚 Stacks & Queues

Data structure programs implementing stack push/pop operations in Python.

| File | Description |
|------|-------------|
| `Push.py` | Stack PUSH operation with overflow check |
| `practiquestpoppush.py` | Practice: push and pop on a stack |
| `studentpractic2.py` | Student record management using stack |

> 💡 Stacks follow LIFO (Last In First Out) — these programs demonstrate push, pop, and overflow handling.
